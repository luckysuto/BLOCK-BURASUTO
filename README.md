# ブロックブラすと — ゲーム一式

## 遊び方
`index.html` をルートに置いて GitHub Pages で公開します。JavaScript の ES Modules を使うため、ローカルで確認するときは `python -m http.server 8000` 等のローカルサーバー経由でアクセスしてください。

- 8×8盤面に3個ずつのピースを配置。回転不可、形状は一様ランダム。
- 縦・横8マスを揃えて消去。配置1マスにつき1点、消去点は20/50/90/140/200点〜、コンボ倍率は1回目1倍、以後+0.5倍。消去なし3手でコンボリセット。
- クラシックと100ステージ。ステージ目標は500点から100点ずつ増加。
- 獲得ポイントはスコア10点につき1P（プレイ終了時）。初回ステージ報酬は100〜1,000P。
- ショップは5カテゴリ×10種類。各カテゴリの1商品目は無料。購入と装備は別。
- BGM10曲、効果音15種のオリジナル合成WAVを同梱。各BGMは約28〜51秒のループ再生用トラックです。
- 保存はブラウザのlocalStorage（容量が小さいゲーム進行データのみ）。設定画面からJSONバックアップを出力・復元可能。ブラウザのデータ消去には注意。

## ファイル構成
- `index.html` : 画面構造
- `style.css` : レイアウト、スキンの描画
- `js/data.js` : 50商品、形状、目標
- `js/game.js` : 盤面、配置、得点、終了判定
- `js/main.js` : UI、操作、ショップ、ステージ
- `js/audio.js` : 10曲の再生と効果音
- `js/save.js` : 保存・バックアップ
- `audio/` : WAV音源

## 操作
スマホはブロックをタップして盤面をタップ、またはブロックをドラッグ。PCはブロックをクリックして盤面をクリック、またはドラッグ。終了時にポイントが加算されます。

## 注意
外部ライブラリ・サーバーは不要。著作権上、既存ゲームの画像・音声は含まず、独自のCSS描画と合成音声を使用しています。ゲームの動作は利用するブラウザ・端末でも確認してください。
